# Paso a paso · Programación avanzada

Ruta de repaso por semanas: Python, POO, estructuras, excepciones, iteradores, funcional,
concurrencia, serialización, redes, interfaces, regex, grafos, NumPy y pandas.
Los ejercicios de hilos, red e interfaces en el navegador son modelos de su lógica.
laboratorios.py contiene ejemplos nativos para practicar las APIs reales.
PLAN-DE-ESTUDIO.md propone diez días de estudio y explica los límites de la ruta.

Sitio estático para GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
Python corre en un Web Worker con Pyodide 314.0.7. No hay servidor de ejecución ni cuentas de estudiantes.
El navegador descarga Python y las bibliotecas desde cdn.jsdelivr.net la primera vez que se necesitan.
Los programas y el progreso se guardan solo en localStorage del navegador de cada participante.
Para cambiar de navegador o migrar desde la versión local: Descargar mi avance → Cargar mi avance.
No se suben soluciones personales ni avances al repositorio. No hay sincronización automática ni historial completo de intentos.

Los ejemplos y enunciados de la aplicación son originales. No son evaluaciones oficiales.
La ejecución limita cada caso a 6 segundos, sin contar la descarga del motor y las bibliotecas.
